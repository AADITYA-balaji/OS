DeathNoteOS
I've loved Death Note ever since I was a kid. I was obsessed with the mind games, the dark vibe, and the notebook itself. That childhood obsession gave me the idea to bring it to life, so I built DeathNoteOS! It's a dark desktop website where you can drag windows around and feel like you are actually in the anime

🚀 Cool Features:

Switch Sides: You can click a button to switch between Kira Mode and L Mode depending on who you want to be

The Notebook: Type anyone's full name right into the Death Note app

60 Second Timer: After you type a name

Ryuk Appears: Once the time runs out,a Ryuk popup hits the screen saying they are eliminated and a creepy Kira laugh sound plays

Moving Windows: You can click and drag the windows anywhere on the screen by holding their headers.



 The 3 Apps:

 Rules: Read the official laws of how the notebook works

 Notebook: The app where you actually type the names

 Devlogs: The behind the scenes 




Note: AI was used to help create the particle effect and for the sound effects
